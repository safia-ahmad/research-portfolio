# Research Portfolio

A modern, responsive portfolio website showcasing my academic background, machine learning projects, research interests, and technical skills.

The website is designed to serve as a central hub for my PhD applications, research collaborations, and professional profile.

## Running Locally

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/research-portfolio.git
```

Go to the project folder

```bash
cd research-portfolio
```

Open

```
index.html
```

in your browser.

No installation or dependencies are required.
